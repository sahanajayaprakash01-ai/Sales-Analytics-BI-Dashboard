# 📊 Sales Analytics & BI Dashboard

## Project Overview

This project demonstrates an end-to-end data analysis workflow using **Python, SQL, and Power BI**.

The objective was to clean and analyze retail sales data, answer business-related questions using SQL, identify important sales trends, and build an interactive Power BI dashboard for business decision-making.

## 🧹 Data Cleaning & Preparation

The dataset contains approximately **9,800 sales records**.

Data preparation included:

- Checking missing values
- Checking duplicate records
- Validating column data types
- Converting Order Date and Ship Date to datetime format
- Checking date consistency
- Investigating unusually high and low sales values
- Validating categorical columns
- Creating a Shipping Days field for shipping analysis

## 📈 Power BI Dashboard

An interactive Power BI dashboard was created with the following KPIs:

- **Total Sales:** $2.26M
- **Total Orders:** ~5K
- **Total Customers:** 793
- **Total Products:** ~2K

Dashboard analysis includes:

- Sales by Category
- Sales by Segment
- Sales by Region
- Sales Trend by Year
- Monthly Sales Trend
- Top Products by Sales
- Sales by Sub-Category
- Sales by Ship Mode
- Sales vs. Shipping Days
- Category and Segment comparison

Interactive slicers were added for:

- Year
- Region
- Category
- Segment

## 💡 Key Insights

- Technology generated the highest sales among the three main product categories.
- The Consumer segment contributed the highest overall sales.
- The West region generated the highest sales.
- Sales increased significantly in the later years of the dataset, with 2018 recording the highest annual sales.
- Phones and Chairs were among the strongest-performing sub-categories.
- Standard Class accounted for the highest sales among shipping modes.
- Sales showed stronger performance during the later months of the year.
